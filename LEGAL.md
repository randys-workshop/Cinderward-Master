# IP & Legal Safety Notes — Cinderward

**Goal:** ship a game (eventually on iOS) that is legally distinct from *Golden Sun*
(Camelot / Nintendo) and *Pokémon* (Game Freak / The Pokémon Company / Nintendo).
Those games are used only as **genre inspiration for mechanics**, never as a source of
names, characters, art, story, music, or code.

## What is and isn't protected (general background, not legal advice)

- **Game mechanics/rules are generally not copyrightable.** Turn-based combat, elemental
  type charts, creature collection, equipment slots, quest markers, and XP/leveling are
  common genre conventions used by hundreds of games. Implementing them is fine.
- **Expression IS protected:** specific character/species names, sprite artwork, music,
  story text, dialogue, map layouts copied verbatim, and distinctive UI trade dress.
- **Trademarks** protect names/logos used to identify a product in commerce.

## How Cinderward stays clear

| Concern | Approach |
|---|---|
| Title | **Cinderward** — coined, not a Golden Sun/Pokémon term. |
| Creatures | **Cindren** — original species, original names (Cindpup, Dewbit, Sproutle, …). No Pokémon or Djinn names. |
| Magic | **Aether Arts / EP** — not "Psynergy". Beast states **Bonded/Roused**, summon **Confluence** — not "Djinn/Set/Standby/Unleash". |
| Capture | **Bind** — a channelled rune sigil ritual. **No ball, capsule, or thrown object of any kind.** |
| Art | 100% procedural, drawn in code. No ripped or traced sprites. |
| Music | Procedural WebAudio chiptune, original patterns. |
| Story / world | Original: the First Flame, Emberwick, Emberwood, Hollowmere, the Ashen Covenant, Vael. No Golden Sun/Pokémon places, characters, or plot text. |
| Font | Press Start 2P — SIL Open Font License (free to embed/use commercially). |
| Code | Original, written for this project. No third-party game code. |

## Known near-misses to clear before a commercial/iOS release

These are **not** Golden Sun/Pokémon conflicts, but a formal trademark search should
review them before launch:

- **"Cinderward"** is also the name of a Nitrux Linux firewall GUI (open-source utility,
  different product category) and a Valheim mod backpack item. Neither is a game product,
  but both live in software-adjacent spaces. Consider a distinctive logo and, if needed,
  a subtitle or alternate mark for the App Store.
- Working title was changed away from earlier candidates that had live conflicts:
  "Sunbound" (active USPTO game-software filing), "Aurelith" (existing game projects),
  "Emberkin"/"Cindral" (used by other games/studios).

## Before release checklist

1. Formal trademark clearance search (USPTO + App Store) for the final title and logo.
2. Confirm no species/move/place name collides with a protected mark in class 9/41.
3. Keep all art/audio/code original; retain authorship records.
4. Add an EULA/privacy policy for iOS; declare no third-party IP.
5. If a name is contested, rebrand the mark only — game content is already original.

*This document is engineering guidance, not legal advice. Consult an IP attorney before
commercial release.*
